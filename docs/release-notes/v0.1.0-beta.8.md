## 修复（Fixes）

- 修复所有消息都已读后 Dock 图标偶尔仍显示未读数 1 的问题：已读状态现在会立即同步到本地未读数，网络延迟或事件丢失不再造成残留。
  Fixed the Dock badge sometimes staying at 1 after everything was read: reading is now applied to the local unread counts immediately, so a delayed fetch or a lost event no longer leaves a stale unread behind.
- 优化粘贴长文本时的卡顿：输入内容不再让整个会话视图随每次变化重绘。
  Reduced lag when pasting long text: typing no longer redraws the whole conversation on every change.
- 发送和编辑时先完整显示消息，末尾以小灰字显示「Sending…」/「Editing…」（与「(edited)」相同），成功后消失；发送失败时右侧出现重试和取消图标。
  Messages now show in full while being sent or edited, with a small gray "Sending…" / "Editing…" at the end (like "(edited)") that disappears on success; a failed send shows retry and cancel icons on the right.
- 消息在顶部导航栏和底部输入框交界处渐隐，不再与面包屑导航重叠，也不再被直接截断。
  Messages fade out at the top bar and above the composer instead of overlapping the breadcrumb or ending in a hard edge.
- 底部输入框略微变矮，上下内边距减小。
  The composer at the bottom is slightly shorter, with less vertical padding.

## 新功能（New features）

- 消息密度：在「设置 › 外观」中新增「消息密度」，可在「常规」和「紧凑」之间选择，紧凑模式缩小消息之间的空白。
  Message density: Settings › Appearance has a new Message density option, Normal or Compact; Compact reduces the space between messages.
- Markdown 表格渲染：消息中的表格以原生表格显示，支持表头、列对齐，过宽时可左右滚动。
  Markdown tables: tables in messages are drawn as native grids with a header row and column alignment, and scroll sideways when wide.
- LaTeX 公式渲染：`$$…$$` 和 `math` 代码块中的公式以原生排版显示（分数、根号、上下标与上下限、矩阵、括号等），可右键复制 LaTeX 源码；句中公式以单行文本显示。
  LaTeX formulas: `$$…$$` and `math` blocks are typeset natively (fractions, roots, scripts and limits, matrices, brackets) with Copy LaTeX on right-click; formulas inside a sentence read as one line of text.
