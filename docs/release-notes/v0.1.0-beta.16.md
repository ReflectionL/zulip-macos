## 修复（Fixes）

- 私聊里连续发消息时不再闪烁：刚发出的消息不会先多出一次头像和名字再收回。
  Sending consecutive direct messages no longer flashes: a just-sent message no longer briefly shows an extra avatar and name before settling.

## 新功能（New features）

- 侧边栏里话题前的图标换成小圆点，使用所属频道的颜色但饱和度更低，不再抢频道的风头。
  Topics in the sidebar now start with a small dot in their channel's colour, less saturated than the channel's own, instead of a heavier icon.
