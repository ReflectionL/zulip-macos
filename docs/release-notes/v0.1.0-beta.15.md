## 修复（Fixes）

- 输入框打字更流畅：输入时不再重绘整个会话，长会话里按键不再卡顿。
  Typing is smoother: keystrokes no longer redraw the whole conversation, so long conversations stay responsive.
- 已读头像显示在消息最后一行的末尾，不再单占一行，消息高度不会随头像移动而变化。
  Read-receipt avatars sit at the end of the message's last line instead of on a line of their own, so message heights no longer change as they move.
- 媒体缓存每个账号上限 512 MiB，超出后删除最久未使用的图片，并清理中断的半截下载。
  The media cache is capped at 512 MiB per account: the least recently used pictures are deleted beyond that, and abandoned partial downloads are cleared.
- 侧边栏刷新更快：话题按频道一次分组，频道多时收到消息不再卡。
  The sidebar refreshes faster: topics are grouped by channel once, so new messages no longer stall it in organizations with many channels.
- 自动更新无法替换应用时，清理应用旁留下的临时副本。
  When an automatic update cannot replace the app, the temporary copy left beside it is removed.

Whether typing feels smoother in long conversations, and whether the read-receipt position looks right.
