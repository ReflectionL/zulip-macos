## 修复（Fixes）

- 优化消息列表的滚动流畅度：悬停操作栏改为悬停时才创建，上下渐隐不再使用整屏遮罩，大图片和头像按显示尺寸解码。
  Smoother timeline scrolling: the hover action bar is built only on hover, the top and bottom fades no longer mask the whole timeline, and large pictures and avatars are decoded at display size.

## 新功能（New features）

- 设置 › 外观新增「字体」，可选择系统字体或本机已安装的任意字体；代码和公式字体不变。
  Settings › Appearance adds a Font option: the system font or any font installed on the Mac; code and math keep their own fonts.
