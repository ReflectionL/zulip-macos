## 修复（Fixes）

- 修复登录前的欢迎页：不再显示虚构的演示组织、假的 Drafts 和一直转圈的频道，侧边栏和顶部栏与登录后保持一致。
  Fixed the window shown before signing in: it no longer shows a made-up demo organization, a Drafts item or a channel that loads forever, and its sidebar and top bar now match the connected window.
- 修复登录表单的回车行为：依次跳转服务器、邮箱、密码，并在最后一栏连接；连接中重复回车不再触发第二次连接。
  Fixed Return in the sign-in form: it now moves through Server, Email and Password and connects from the last field, and pressing it again while signing in no longer starts a second attempt.
- 修复重启后已保存账号重连前会闪现演示界面的问题：现在只显示「Reconnecting…」。
  Fixed the demo window flashing on launch while a saved account reconnects: it now shows "Reconnecting…" only.

## 新功能（New features）

- 欢迎页改版：登录表单直接放在窗口中，样式与登录后的界面一致；登录失败后焦点回到密码框。
  A redesigned welcome screen: the sign-in form sits in the window itself in the same style as the connected app, and the focus returns to the password field after a failed sign-in.
