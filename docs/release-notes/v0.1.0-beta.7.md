## 修复（Fixes）

- **锁屏之后收到的消息没有 Dock 红点**：以前程序只看自己"是不是最前面的程序"来判断你有没有在看消息，但锁屏、屏幕休眠时，最前面的程序并不会变，所以程序以为你还在看当前打开的那个会话：新消息一到就被当成已读（所以没有红点），通知也因为"正在看这个会话"被跳过。现在锁屏、屏幕休眠、切换到其他登录用户时，都算作"不在看"：新消息会保持未读、Dock 红点照常显示，并且会弹出通知。解锁（或屏幕唤醒）回来后，当前打开的会话会立刻刷新并标为已读。
- **输入框明明只有一行字却占两行**：以前文字一行、下面再单独一行放 + 和发送按钮。现在 +、文字、发送按钮放在同一行，空的输入框只有一行高；文字多了会向上长高（最多六行），按钮始终留在底部。
- **+ 按钮很难点中**：以前只有 + 符号本身能点。现在是一个稍大的圆形点击区域，鼠标移上去会亮一点，按下时更亮。
- **日期分隔线过夜后不更新**：日期本来就是按系统时区算的，但每条分隔线的文字只在第一次画出来时算一次，之后不会重算。所以一个会话一直开着过了午夜（或者电脑睡眠过夜），昨天的消息还写着 Today，今天的新消息也写 Today。现在过了午夜、改了时区、切回程序或电脑唤醒时都会重新计算。另外，系统设成 12 小时制时，鼠标悬停显示的时间以前没有上午/下午（晚上 7:52 显示成 07:52），现在会带上 a/p；24 小时制不变。

## 新功能（New features）

- **自定义状态**：点左下角自己的头像，会弹出个人面板，可以"设置状态"：选一个表情、写一句话（最多 60 个字），或者直接点 Zulip 网页版同款的六个常用状态（开会中、通勤中、生病请假、休假中、远程办公、在办公室）。已有状态可以再编辑或一键清除。和网页版互通：在网页版改的状态这里会同步过来，反过来也一样。
- **显示别人的状态**：和 Zulip 网页版一样，状态表情显示在名字后面（消息里的发送人、左边的私信列表）；鼠标停在私信列表的名字上能看到状态文字，打开和某人的私信时，顶部会显示"表情 + 状态文字 · 在线情况"。别人用了组织自定义的图片表情时暂时不显示表情，只显示文字。
- **隐身模式**：同一个个人面板里有"Invisible mode"开关，打开后别人看到你是离线，但你照常收发消息；开着时左下角名字旁会有一个小眼睛图标提醒你。

**还需要你反馈**：锁屏后让别人给你发一条私信，看看 Dock 是否出现红点、是否收到通知；解锁并看过消息后红点是否消失；输入框是否变成一行、+ 按钮是否好点；程序开着过一夜后 Today / Yesterday 是否正确；设置的状态和隐身模式在网页版里看是否一致。
