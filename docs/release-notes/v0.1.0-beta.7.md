## 修复（Fixes）

- **锁屏之后收到的消息没有 Dock 红点**：以前程序只看自己"是不是最前面的程序"来判断你有没有在看消息，但锁屏、屏幕休眠时，最前面的程序并不会变，所以程序以为你还在看当前打开的那个会话：新消息一到就被当成已读（所以没有红点），通知也因为"正在看这个会话"被跳过。现在锁屏、屏幕休眠、切换到其他登录用户时，都算作"不在看"：新消息会保持未读、Dock 红点照常显示，并且会弹出通知。解锁（或屏幕唤醒）回来后，当前打开的会话会立刻刷新并标为已读。
- **输入框明明只有一行字却占两行**：以前文字一行、下面再单独一行放 + 和发送按钮。现在 +、文字、发送按钮放在同一行，空的输入框只有一行高；文字多了会向上长高（最多六行），按钮始终留在底部。
- **+ 按钮很难点中**：以前只有 + 符号本身能点。现在是一个稍大的圆形点击区域，鼠标移上去会亮一点，按下时更亮。
- **日期分隔线的 Today / Yesterday 不对**：日期本来就是按系统时区算的，但每条分隔线的文字只在第一次画出来时算一次，之后不会重算。所以一个会话一直开着过了午夜（或者电脑睡眠过夜），昨天的消息还写着 Today，今天的新消息也写 Today。现在过了午夜、改了时区、切回程序或电脑唤醒时都会重新计算。另外，系统设成 12 小时制时，鼠标悬停显示的时间以前没有上午/下午（晚上 7:52 显示成 07:52），现在会带上 a/p；24 小时制不变。
