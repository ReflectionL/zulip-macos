## 修复（Fixes）

- 刚截下的屏幕截图可以直接从缩略图拖进会话上传，其他应用里的图片也可以拖入，不必先保存成文件。
  A screenshot can be dragged straight from its thumbnail into a conversation, as can pictures from other apps, without saving them first.
- 修复部分 emoji 设为状态时报 "bad request"：emoji 改用 Zulip 自己的名称和编码，"In a meeting" 预设也一并修正。
  Fixed some emoji failing with "bad request" when set as a status: emoji now use Zulip's own names and codes, and the "In a meeting" preset is corrected.
- 修复 Dock 图标显示未读但实际找不到未读消息：系统机器人和已停用账号发来的私信现在会出现在私信列表里，群聊私信暂不计入角标。
  Fixed the Dock badge showing unread messages that could not be found: direct messages from system bots and deactivated accounts now appear in the list, and group chats no longer count on the badge for now.
- 修复发送新消息时已读头像闪一下：头像在新消息有了结果后一次性移过去。
  Fixed the read-receipt avatars flashing when a new message is sent: they now move to it once its readers are known.

**待确认 / Feedback needed**：截图缩略图能否直接拖入上传，之前报错的状态 emoji 能否保存，Dock 角标是否与实际未读一致，发送消息时是否还会闪。
Whether a screenshot thumbnail uploads when dropped, whether the emoji that failed before now save as a status, whether the Dock badge matches what is unread, and whether sending still flashes.
