# Zulip Mac v0.1.0-alpha.1

This is the first friend-testing build of the independent native Zulip Mac
client. It is an early preview, not an official Zulip client or a beta-quality
release.

## Included

- Zulip Cloud and standard HTTPS server login with API keys stored in Keychain.
- Live Inbox, mentions, starred and unread views; channel, topic, and direct
  message navigation; history paging and server-side search.
- Sending, editing, deleting, reactions, starring, and read/unread actions with
  visible pending, rollback, and retry states.
- Topic creation drafts, topic rename, message moves, uploads, authenticated
  media caching, and native rendering of common Zulip message content.
- The current two-column, keyboard-aware macOS 26 interface and original app
  icon.

## Requirements and installation

- macOS 26 or newer.
- Apple Silicon (`arm64`) only.
- Open the DMG and drag **Zulip Mac** to the **Applications** alias.

This build is ad-hoc signed and is **not notarized** because Developer ID
credentials are not configured. Gatekeeper may therefore require the first
launch to use Finder's **Open** context-menu action and confirm once. Do not
disable Gatekeeper globally.

## Known limitations

- Offline reading/draft recovery, notifications, and the final keyboard pass
  are not complete.
- One active account only; browser SSO, self-signed certificates, Intel Macs,
  App Store distribution, and administration remain out of scope.
- Zulip Cloud has been exercised live. Standard self-hosted behavior is covered
  by protocol mocks but has not yet passed the real self-hosted release smoke.
- This unnotarized alpha does not satisfy the later `REL-005` beta gate.

Credentials remain in macOS Keychain and process memory; they are not stored in
SQLite, fixtures, release assets, or logs.
